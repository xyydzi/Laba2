# Tic-Tac-Toe — Minimax AI

## Описание проекта

Консольная игра «Крестики-нолики» на C# для двух участников: человека и искусственного интеллекта.

- Человек играет за `X`.
- Искусственный интеллект играет за `O`.
- ИИ использует алгоритм Minimax для выбора оптимального хода.
- Игра заканчивается победой одного из игроков или ничьей.

## Требования

- Установленный .NET SDK.
- Visual Studio или другая среда разработки для C# (необязательно, если запускать через терминал).

## Как запустить игру

1. Скачайте или клонируйте репозиторий.
2. Откройте терминал в папке проекта, где находится файл `.csproj`.
3. Выполните команду:

   ```bash
   dotnet run
   ```

4. Дождитесь появления игрового поля.
5. Введите номер свободной клетки от 1 до 9 и нажмите Enter.

## Нумерация клеток

```text
1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9
```

## Используемый алгоритм

Minimax рекурсивно рассматривает возможные ходы до конца партии.

- Победа ИИ оценивается в `+10`.
- Победа человека оценивается в `-10`.
- Ничья оценивается в `0`.

ИИ выбирает ход с максимальной оценкой, учитывая лучший возможный ответ соперника.

## Структура проекта

- `Program.cs` — игровой процесс, проверка победителя и реализация Minimax.
- `README.md` — описание проекта и инструкция по запуску.
- `report.md` — отчёт по лабораторной работе.
